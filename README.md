# FCC Technical Onboarding Program (FTOP)
**Tehran FCC Group - CERN**  

---

FTOP is a structured technical training program run by the Tehran FCC Group. It builds a core team of physicists and students proficient in the software, simulation, and data analysis tools required for active contribution to the Future Circular Collider (FCC) project at CERN.

This is the **central hub repository** of the program. It contains program documentation, schedules, participant guidelines, and links to all phase repositories. Code, exercises, and learning materials live in their respective phase repositories listed below.

---

## Getting Started

To start read the documents provided at `./docs`. And then start contrbiting as the guidlines suggest.

## Participation Rules

- All work must be committed to the relevant phase repository. Contributions with no GitHub record do not count.
- Each participant owns at least one session per quarter and is responsible for its preparation and the corresponding repository entry.
- Pull requests must be reviewed by at least one other participant before merging.
- Two or more consecutive weeks without a commit is considered inactive participation.

Full details in [CONTRIBUTING.md](./CONTRIBUTING.md).

---

## Prerequisites

Participants are expected to have:

- Undergraduate-level knowledge of particle physics or a closely related field
- Working knowledge of Python or C++ (both preferred)
- Working knowledge of Git and GitHub (mandatory)
- Basic Linux and command-line familiarity
- A GitHub account added to the [hsqcd-collab](https://github.com/hsqcd-collab) organization
